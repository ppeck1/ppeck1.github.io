> **TL;DR:** Philosophy Atlas is a local knowledge system that treats philosophical problems as navigable terrain. It starts from governed structured data and generates static pages for problem folds, lineage maps, timelines, matrices, and philosopher dossiers.

## What it is

Philosophy Atlas is not a reading list dressed up as a website. It is a generated atlas for seeing how ideas relate across problems, thinkers, historical context, and recurring tensions.

The current v4/v4.2 build uses structured JSON as the source of truth, then generates a static HTML interface. The root page is an "Atlas Cockpit" with multiple ways into the same library:

- Terrain: a global problem constellation
- Folds: problem-centered entry points
- Lineages: cross-problem thinkers and typed relationships
- Timeline: chronology without pretending every relationship is direct transmission
- Matrix: coverage, gaps, and recurring civilization questions

## Why it matters

The project demonstrates the same pattern as the clinical and operator tools elsewhere on this site: make complexity legible without flattening it.

For philosophy, that means keeping uncertainty visible. Comparative relationships are marked differently from documented historical transmission. Generated dossiers can show positions, concepts, questions, timelines, texts, and source notes without claiming more certainty than the underlying data supports.

## Current shape

The latest local handoff reports:

- 1,053 governed nodes
- 1,085 governed edges
- 179 cross-problem entities
- 27 shared rich philosopher pages
- 35 slice-specific governed dossier pages linked into the shared layer

The deepest authored modules currently cover thinkers such as Heraclitus, Parmenides, Aristotle, and Socrates. Other thinker pages are generated from the graph and marked as expansion targets rather than pretending to be finished.

## What This Demonstrates

- Governed data as the source of truth for a public-facing knowledge surface
- Static generation for durable, portable interfaces
- Graph thinking that separates lineage, comparison, recurrence, and uncertainty
- A practical bridge between personal study, knowledge architecture, and publishable proof artifacts
